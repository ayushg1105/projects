# 🤖 Digibuddy Chatbot UI

Digibuddy is a frontend web template for a chatbot application. It provides a clean and responsive user interface for users to interact with a chatbot, log in, view tutorials, and submit feedback.

## ✨ Features
- **Login & Registration Pages:** Simple forms for user authentication.
- **Main Chat Interface:** A dedicated page (`chat.html`) for interacting with the Digibuddy bot.
- **Tutorials Section:** A page to learn how to use the bot.
- **Feedback Form:** A styled form to collect user feedback.
- **Interactivity:** Basic JavaScript for page routing and form handling.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Vanilla CSS)
- Vanilla JavaScript

## 🚀 Getting Started

This is a static frontend project, so no complex backend or build process is required!

1. Clone or download the repository.
2. Navigate to the `digibuddy-chatbot` directory.
3. Open `index.html` in your favorite web browser to view the application.

## 📁 File Structure
- `index.html`, `login.css`: Landing and authentication pages.
- `main.html`, `main.css`: The primary dashboard.
- `chat.html`, `chat.css`: The chatbot messaging interface.
- `tutorials.html`, `tutorials.css`: Help and guide section.
- `feedback.html`, `feedback.css`: User feedback form.
- `script.js`: Handles basic DOM events and navigation between pages.
