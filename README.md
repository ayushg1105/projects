# Beginner Projects Collection

Welcome to the **Beginner Projects Collection**! 🚀 This repository contains a set of simple, easy-to-understand projects designed for beginners to learn and explore different domains of software development, ranging from frontend web design to computer vision and machine learning.

## 📂 Projects Overview

### 1. [Face Mask Detection System](./face%20mask%20detection)
A real-time computer vision application that detects whether a person is wearing a face mask or not. It uses a webcam feed, OpenCV for face tracking, and a TensorFlow/Keras Deep Learning model for classification. 
- **Tech Stack:** Python, OpenCV, TensorFlow, Keras

### 2. [Digibuddy Chatbot UI](./digibuddy-chatbot)
A frontend web template for a chatbot application named Digibuddy. It includes pages for login/registration, a main chat interface, tutorials, and feedback forms, complete with styling and basic interactivity.
- **Tech Stack:** HTML, CSS, JavaScript

### 3. [Color Detection App](./color%20detection%20app)
An application built to identify colors. *(Check the directory for more details)*.
